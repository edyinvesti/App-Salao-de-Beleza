## 2026-08-07 - Testimonial Carousel Keyboard Nav & Focus Indicators
**Learning:** Generic div elements as indicators on carousels lack focus states, keyboard accessibility, and standard ARIA roles/attributes. Utilizing standard HTML `<button>` elements of type `"button"` alongside appropriate `:focus-visible` styling dramatically improves accessibility with no structural layouts regressions, provided default user-agent button styles are reset (e.g. `border: none; padding: 0; display: block;`).
**Action:** Always refactor custom clickable `<div>` elements into semantic `<button type="button">` elements with appropriate `aria-label` / `aria-current` / `aria-expanded` properties and style them with robust, custom `:focus-visible` styles with small offsets to maintain a high-quality visual system on keyboard interaction.
