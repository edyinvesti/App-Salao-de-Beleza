## 2026-03-22 - Testimonials Dot Carousel and Mobile Navigation Hamburger Accessibility Improvements

**Learning:** Micro-UX enhancements like changing non-semantic pagination divs to buttons, adding correct `aria-*` tags (`aria-label`, `aria-current`, `aria-expanded`), and styling focus indicators (`:focus-visible`) heavily improve WCAG / accessibility conformity without layout breakages if correct CSS styling overrides are introduced.
**Action:** Always verify custom controls are semantic interactive tags and include proper language translation details (e.g. `pt-BR`) as well as browser-default style resets.
