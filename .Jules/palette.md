## 2026-10-22 - Global Focus Visible Indicators
**Learning:** Adding `:focus-visible` outline and box-shadow variables at the base CSS level ensures consistent visual affordances for keyboard navigators across custom styled buttons, anchor links, and form elements without affecting mouse/touch users.
**Action:** Always include global `:focus-visible` styles with CSS variable fallbacks (`--primary`, `--primary-glow`) in static landing page design systems.
