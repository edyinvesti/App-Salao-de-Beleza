## 2025-08-09 - Accessible Interactive Carousel Dots and Tab Navigation
**Learning:** Refactoring interactive `<div>` dots to `<button>` elements is critical for keyboard and screen reader accessibility, but requires explicitly resetting button styles in CSS (`border: none; padding: 0; display: block;`) to avoid browser-specific layout/flex regressions. For tab components, programmatic WAI-ARIA injection (via JavaScript `role="tablist"`, `role="tab"`, and `role="tabpanel"`) ensures complete semantic compliance and roving tabindex keyboard navigation (arrow keys, Home/End) while keeping the raw HTML simple and robust.
**Action:** Always start interactive custom element refactors by auditing native keyboard focus behavior and applying standard WAI-ARIA role patterns alongside explicit CSS resets for customized interactive button components.
