## 2026-03-24 - [Accessibility: ARIA Tabs and Carousel Buttons]
**Learning:** For interactive components like tabs and carousels, following WAI-ARIA patterns (roles, states, and keyboard navigation) is crucial for accessibility and provides a more professional feel. Using `:focus-visible` allows for clear focus rings only when needed.
**Action:** Always implement roving tabindex and arrow key navigation for tablists, and ensure carousel controls use semantic `<button>` elements with ARIA labels.
