## 2026-03-17 - Carousel Dots Accessibility and Focus Refactor
**Learning:** Carousel navigation indicators should use semantic `<button>` elements rather than generic `<div>` elements to guarantee standard tab sequences and accessibility reporting. When refactoring `<div>` elements to `<button>` elements, we should explicitly reset standard browser button styles (border, padding, and display) to prevent visual regressions, and specify `:focus-visible` styles with customizable outline-offsets to ensure keyboard indicators look clean and aligned across both large content blocks and small interactive dots.
**Action:** When creating or editing carousel indicators in JavaScript, build them using `document.createElement('button')` with `type="button"`, manage `aria-current` programmatically during updates, and align `:focus-visible` outline offsets in CSS with specific component guidelines.
