## 2026-08-02 - Accessible Testimonial Carousel and Global Focus Indicators
**Learning:** For interactive controls like carousel indicators/dots, div elements lack native keyboard focusability and screen reader accessibility. Refactoring these to native HTML buttons with explicit dynamic attributes (`aria-current` and `aria-label` in the site's primary language) drastically enhances accessibility. Additionally, a clear `:focus-visible` global style combined with appropriate `outline-offset` provides clear visual feedback for keyboard users.
**Action:** Always represent interactive dots with `<button type="button">`, reset default button styles to avoid layout regressions, provide dynamic `aria-current="true"|"false"` and `aria-label="Ir para o slide X"`, and configure high-visibility global focus states.
